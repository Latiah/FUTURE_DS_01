# FUTURE_DS_01
# Task 1: Business Sales Performance Analytics

Analyze business sales data to identify revenue trends, top-selling
products, high-value categories, and regional performance.

This task helps a business answer important questions such as:
- Which products generate the most revenue?
- How do sales change over time?
- Which categories or regions are most profitable?
- Where should the business focus to grow faster?

# Tools used
Power BI
